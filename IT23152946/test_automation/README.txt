# IT3040 Assignment 1 - Transliteration Accuracy Testing

## Project Description
This repository contains the Playwright automation files used for IT3040 Assignment 1 - Option 1.

The purpose of this project is to test the Chat Sinhala transliteration function available at:

https://www.pixelssuite.com/chat-translator

The test cases check how accurately chat-style Singlish inputs are converted into Sinhala outputs.

## Files Included
- Assignment 1 - Test cases.xlsx
- test_automation.py
- test_automation_safe.py
- README.md

## Requirements
- Python 3.11 or above
- Google Chrome
- Playwright
- openpyxl
